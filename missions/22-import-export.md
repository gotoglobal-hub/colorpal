# Mission 22: Import & Export

Your users want to be able to back up their data and share it with friends directly.

This feature will allow users to export their paint collection, projects, and palettes to a common format like JSON or CSV. They should also be able to import a file in the same format to add new paints or palettes to their collection.

**Goal:** Add "Import" and "Export" buttons that can handle data in a portable format.
