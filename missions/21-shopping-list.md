# Mission 21: Shopping List / Wishlist

Running out of a key color mid-project is frustrating. This feature will help users plan their paint purchases.

Users should be able to add paints to a "Shopping List" or "Wishlist". This list should be easily accessible and printable. For an advanced version, you could link to online stores where the paint can be purchased, building on the price tracking feature.

**Goal:** Create a separate "Shopping List" view where users can manage paints they intend to buy.
